Installer

Trois gestes, et un message à connaître la première fois.

Sailaware n'est pas encore signé par Apple ni par Microsoft. Votre système vous prévient donc à la première ouverture : l'application est saine, voici comment l'autoriser.

Sur Mac
  1. Ouvrez le fichier .dmg et glissez Sailaware dans le dossier Applications.
  2. Ouvrez Sailaware depuis le dossier Applications.
  3. Saisissez votre clé au premier lancement.
macOS affiche « endommagé » à l’ouverture ?

macOS bloque les apps non signées téléchargées sur Internet (message « endommagée »). L'application est saine : voici comment l'autoriser. Placez d'abord Sailaware dans le dossier Applications, puis collez cette commande dans le Terminal :

xattr -dr com.apple.quarantine "/Applications/Sailaware.app"

Autre méthode : dans le dossier Applications, faites un clic droit sur Sailaware, puis Ouvrir, puis Ouvrir.

Sur Windows
  1. Lancez l'installeur .exe.
  2. Ouvrez Sailaware depuis le menu Démarrer.
  3. Saisissez votre clé au premier lancement.
Windows affiche « Windows a protégé votre ordinateur » ?

C'est l'avertissement de Windows pour les installeurs non signés. Cliquez sur « Informations complémentaires », puis sur « Exécuter quand même ».

Les mises à jour

Une fois installé, Sailaware se tient à jour.

L'application cherche une nouvelle version à son lancement, puis toutes les six heures. Elle vous la propose, et ne l'installe qu'avec votre accord.
