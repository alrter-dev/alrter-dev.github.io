# alrter-dev.github.io

Site de **Sailaware** (https://sailaware.app) — logiciel de navigation pour macOS et Windows :
routage météo, cartes hors ligne, instruments du bord, veille, point astral.

Site statique bilingue FR/EN, publié par GitHub Pages. Huit pages : `index`, `offshore`, `coastal`,
`features`, `routing`, `sparring-skipper`, `download`, `about`. Fichiers communs dans `assets/` :
`site.css` (styles), `site.js` (langue, jour/nuit, menu), `eventail.js` + `scenes.js` (l'animation
des routes), `resultats.js` (les 161 essais de routage), `fonts/` (JetBrains Mono).

Le français est écrit dans les pages ; l'anglais est porté par chaque élément (`data-en`).
Le téléchargement est réservé aux clés bêta : seules leurs empreintes SHA-256 sont dans `download.html`.
